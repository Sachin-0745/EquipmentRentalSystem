<p>              Online Equipment Rental System</p><p>          SOFTWARE RQUIREMENT SPECIFICATIONS (SRS)</p><p>1. Purpose of Software</p><p>The Online Equipment Rental System is a web-based platform that allows users to rent equipment such as cameras, tools, sports items, musical instuments and lab equipment. </p><p>The system aims to replace manual rental processes with a digital, efficient, and error-free solution. </p><p>Primary Objectives</p><p>Provide an online platform for browsing and renting equipment.</p><p>Automate equipment availability checking.</p><p>Calculate rental costs automatically.</p><p>Manage equipment returns and payment status.</p><p>Maintain accurate rental records.</p><p>2. Stakeholders</p><p>Customers (Renters)</p><ul><li>Rent items</li><li>View rental history</li><li>Return equipment</li></ul><p>Admin (Owner/Manager)</p><ul><li>Manage equipment inventory</li><li>Approve rental requests</li><li>Update returns and payment status</li><li>Monitor system data</li></ul><p>Development Team</p><ul><li>Build and maintain the system</li></ul><p>3. Scope</p><p>The system is a web-based application that allows customers to rent equipment and admins to manage rentals.</p><p>The system shall:</p><p>Allow users to register and log in.</p><p>Allow users to browse and search equipment.</p><p>Allow rental requests with availability checking.</p><p>Calculate rent based on duration.</p><p>Manage returns and payment status.</p><p>Store and manage rental records.</p><p>4. Functional Requirements</p><p>FR-1: User Registration &amp; Login</p><p>Description:</p><p>The system shall allow users to create accounts and log in securely.</p><p>Inputs</p><ul><li>Name</li><li>Email</li><li>Password</li><li>Processing</li><li>Validate user details</li><li>Store user credentials</li><li>Authenticate login</li></ul><p>Outputs</p><ul><li>Successful login message</li><li>Error message for invalid credentials</li><li>User Interaction</li><li>User enters registration details.</li><li>System validates and stores data.</li><li>User logs in using credentials.</li></ul><p>FR-2: Equipment Browsing &amp; Search</p><p>Description:</p><p>The system shall allow users to browse and search available equipment.</p><p>Inputs</p><ul><li>Equipment name or category</li><li>Processing</li><li>Search database</li><li>Filter available equipment</li></ul><p>Outputs</p><ul><li>List of equipment with price and availability</li><li>User Interaction</li><li>User searches equipment.</li><li>System displays matching results.</li></ul><p>FR-3: Equipment Rental Request</p><p>Description:</p><p>The system shall allow users to request equipment rental.</p><p>Inputs</p><ul><li>Equipment ID</li><li>Start date</li><li>End date</li><li>Processing</li><li>Check availability</li><li>Reserve equipment if available</li></ul><p>Outputs</p><ul><li>Rental confirmation</li><li>ΓÇ£Not AvailableΓÇ¥ message</li><li>User Interaction</li><li>User selects equipment.</li><li>System verifies availability.</li><li>Rental request is confirmed.</li></ul><p>FR-4: Rent Calculation</p><p>Description:</p><p>The system shall calculate rental cost automatically.</p><p>Inputs</p><ul><li>Number of rental days</li><li>Price per day</li><li>Processing</li><li>Multiply days by price</li></ul><p>Outputs</p><ul><li>Total rental cost</li></ul><p>FR-5: Equipment Return &amp; Payment Status</p><p>Description</p><p>The system shall manage equipment returns and update payment status.</p><p>Inputs</p><ul><li>Rental ID</li><li>Return confirmation</li><li>Processing</li><li>Update rental record</li><li>Mark payment status</li></ul><p>Outputs</p><ul><li>Rental closed</li><li>Payment status updated</li></ul><p>5. Non-Functional Requirements</p><p>NFR-1: Performance</p><p>Support multiple users simultaneously.</p><p>System response time Γëñ 2 seconds for common operations.</p><p>NFR-2: Security</p><p>Secure login authentication. </p><p>Prevent unauthorized access.</p><p>Protect user and rental data.</p><p>NFR-3: Usability</p><p>Simple and user-friendly interface. </p><p>Easy navigation for non-technical users.</p><p>NFR-4: Reliability</p><p>Ensure accurate storage of rental and payment data. </p><p>Prevent duplicate or incorrect entries.</p><p>NFR-5: Scalability</p><p>Support future mobile app integration. </p><p>Allow addition of online payment features.</p><p>6. System Constraints</p><p>SC-1: Technical Constraints</p><p>Web-based application. </p><p>Frontend: React (JavaScript)</p><p>Backend: Node.js</p><p>Database: mongoDB</p><p>SC-2: Platform Constraints</p><p>Must run on modern web browsers.</p><p>Requires internet connectivity.</p><p>SC-3: Budget Constraints</p><p>Student-level project with limited resources.</p><p>7.
